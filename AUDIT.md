# Аудит функций

Здесь перечислены функции из `src`, которые приложение напрямую не вызывает из `main.ts` после перехода на `BookCatalog`.

`formatBook` из `src/task1-types.ts` — полезна. Её можно использовать для единого форматирования книги при экспорте или в компактном списке.

`calculateAverageYear` из `src/task1-types.ts` — полезна. Её можно использовать в будущей статистике каталога, например для показа среднего года издания.

`addBook` из `src/task2-functions.ts` — полезна как пример функционального способа добавления книги и для сравнения с методом класса `BookCatalog`. Сейчас приложение использует метод класса; функция остаётся для учебного примера и существующих тестов.

`removeBook` из `src/task2-functions.ts` — полезна как пример функционального способа удаления книги и для сравнения с методом класса `BookCatalog`. Сейчас приложение использует метод класса; функция остаётся для учебного примера и существующих тестов.

`getBook` из `src/task2-functions.ts` — полезна. Её можно использовать, чтобы находить книгу для просмотра подробностей или редактирования по идентификатору.

`filterByMinRating` из `src/task3-filters.ts` — полезна. Её можно подключить, если в интерфейсе появится фильтр по минимальному рейтингу.

`filterAndSortBooks` из `src/task5-utils.ts` — полезна как готовая композиция поиска и сортировки. Её можно использовать в других экранах или функциях, которым понадобится тот же функционал без методов класса.

Все перечисленные функции оставлены в коде и отмечены JSDoc-комментарием `@deprecated`, поскольку могут пригодиться как учебные примеры или для будущих функций. `filterByTitle` и `sortBooks` сюда не включены: их использует `BookCatalog`.
